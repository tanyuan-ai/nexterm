Minimal no-image WordPress journal with terminal-style login and error pages.

== Description ==

A terminal-inspired WordPress theme: sidebar CRT companion (face or custom
text with typewriter/scramble effects), topbar status LED with customizable
status text, three-way menu alignment, client-side post filtering, and dark
palettes configurable in the Customizer.
